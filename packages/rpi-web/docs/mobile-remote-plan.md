## 一、目标与边界

两个可独立验收的交付物，共用一套「远程 + 窄屏」联调环境：

1. **新版 rpi-web 窄屏适配回归**——现有单页应用在 ≤767px 视口下完成关键闭环；
2. **远程连接形态**——移动浏览器 → 云端 rpi-web 实例的认证、凭据与弱网口径。

## 二、「适配移动端」验收口径（建议稿）

- **目标视口**：360–767px（手机竖屏为主），768–1199px（平板/分屏）只做不破版校验。
- **可完成闭环**（每一项在 360px 宽下可操作、无横向滚动）：
  1. 读会话：打开既有会话、滚动回看、加载更早记录；
  2. 发消息：输入、附件、发送；运行中发送 → 走 steer 入队；
  3. 切换项目：侧栏抽屉化（现状 `sidebar-backdrop mobile-only` 已有），可开合；
  4. 停止运行：abort 按钮可达（触达面积 ≥44px）。
- **退化规则**：inspector / workbench / execution-trace 窄屏不并排，入口进工具栏；
  composer 指标行允许折叠。
- **回归基线**：`styles.css` 移动端断点（262px 侧栏值）+ `desktop.css` 767px
  媒体查询已存在；本项是对新 UI 的重新回归，不是重写。

## 三、「连接移动端 / 云服务器」部署形态（建议稿）

| 形态 | 适用 | 认证 | 结论 |
|---|---|---|---|
| A. 自托管直连 | 个人/小团队，有公网 IP 或反代 | `RPI_WEB_PASSWORD` 单一共享密码 | **推荐起点**：零新代码，rpi-web 已带认证与 SSE |
| B. 反代/TLS 终止 | A 之上加 HTTPS | 同上 + TLS | 必须：密码模式必须与 TLS 同用（明文 3030 不暴露公网） |
| C. 中继/账号体系 | 多用户、免公网 IP | 需要新组件 | 超出本 issue：依赖 #295 的路径授权契约，先不做 |

- **凭据保存**：不新增存储；浏览器记住密码交给平台密码管理器。
  不做「记住我」长期 token（弱设备丢失面大）。
- **弱网 SSE 口径**（与 #301 对齐）：
  - SSE 断开由浏览器 `EventSource` 自动重连，UI 显示 reconnecting；
  - host 退休（idle 回收）由现有 `hostIsRetired` 探测 + `reopenHost` 恢复；
  - 命令层 GET 已有超时+退避重试（#301 分支）；POST 不重试（非幂等）；
  - 移动端切后台/回前台：现有 `visibilitychange` 探针已覆盖，回归时验证。
