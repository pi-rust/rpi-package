# 通用写作方法

本技能负责怎样加工材料、写出解释与改善文字。流程编排来源是 `.rpi/SYSTEM.md`，由系统提示词选择题材模式及当前工作阶段；本技能不另设整篇流程、阶段跳转或发布决定。**自然表达和去 AI 味是全流程质量要求：材料加工、结构设计和起稿时就要避免模板腔，阶段六再集中复读和返修，不能把它当成最后一次表面润色。**

文章任务先完整读取本技能，具体方法按当前阶段取用。不预加载所有题材模式；系统提示词选择模式后再读取相应文件。

## 材料加工与成文设计方法

创作与完整改稿使用 `references/material-to-article.md` 和 `references/reader-first-writing.md`。工作底稿模板、事实与解释的对应方法、各节判断与承接设计都在其中。按需参考 `references/author-profile.md`；本次指定样稿优先。

原稿/资料提供事实，风格样稿提供表达参考，两者分开；不将样稿经历、数字和结论移植到新文章。改稿识别具体缺点和关键保留项，有效段落可以保留。没有更好的解释或阅读路径时，不为体现“改过”增加标题、列表和篇幅。

记录核心事实与来源/版本/条件，说明每条事实支持什么、怎样解释、结论到哪里为止。给材料一个具体用途，处理反例与缺口，保留影响结论的限定。工作记录只包含可核查的事实、证据和编辑决定，不要求保存逐步思考过程。

成文设计从经证据校正的核心判断出发，选择开头、贯穿例子和理解顺序。各节写清判断、证据、解释任务和承接，不能只列术语。标题与图表都服务于同一个阅读目标；图表计划包含位置、解释问题、形式和来源，不将计划当作已经完成的图片。

成文设计同时写下表达风险：可能出现的空泛预告、机械对偶、重复总结、术语堆叠和不属于作者声音的“我们”。起稿时优先用具体动作、因果和限制解决这些风险；阶段六再按实际原句返修，不凭词表批量替换。

## 来源与事实方法

有外部事实、变化信息或关键争议时查找可靠来源并读原文；版本行为核对源码，实验结论核对数据。用户已有的可靠材料先核查，不凑搜索次数；搜索摘要只用于找线索。

研究记录采用 `docs/writing/research-template.md`，原文可用 source_capture 留档，关键引文按 material-to-article 的方法核对。区分事实、来源观点、亲历、推断和示意，不能编造经历、实测、引语、历史细节或代码行为。

核对版本、环境、统计对象、单位与计算顺序；来源片段存在还要核对上下文是否支持正文主张。无法核实的关键事实标明缺口，不给凭记忆写出的内容挂上未读来源。

## 正文方法

从读者的问题与具体材料写起。关键段落让读者看到发生了什么、凭什么这样判断、为什么与他有关。正文补上材料与判断之间的解释，不将各来源摘要排成章节，也不机械复制工作表的栏目名。

保留有用的具体数字、动作、失败、对照和反常现象。必要术语随例子解释；影响结论的条件就近说明。可以删去无关背景，但不能把论证压成泛化建议。

按题材选择叙事、解释或评论的节奏，不强套“背景—原理—实践—总结”。用连贯段落推进，列表用于真正并列的事项和操作；同一答案不在各节反复总结。

可读性在写作时落地，不留到审稿：一句一义，超长句直接拆开；结论与依据就近出现；术语第一次出现就解释；粗体、破折号和列表不做节奏工具。**这些要求从初稿开始执行；阶段六负责发现遗漏、记录具体替换并复读，不是把整篇文章改成统一的 AI 反面腔。**语言层面的 AI 味与可读性返修方法见 `references/humanizer.md`。

图表承担证据或解释任务，放在相关论述附近，图注说明阅读重点与限定。不设图数配额，不伪造实测图；具体制作由系统提示词选用 visualize 或 image 方法。

## 具体审稿方法

使用 `references/editorial-gate.md` 审读实际稿件的内容、结构、标题与阅读负担，使用 `references/humanizer.md` 返修语言自然度与可读性，使用 `references/empathy-pass.md` 检查读者理解与温度，使用 `references/quality-checklist.md` 核对交付文本。审稿顺序和进入验收的决定由系统提示词负责。

源码、架构、机制、评测和排错文章不能只做抽象优缺点审稿：先标出比较对象及层级，再选择一个具体动作追踪两条实际路径，记录入口、核心调用、结果写回、停止/清理和扩展边界，并写明关键不变量由谁承担。若正文或工作记录没有这些内容，说明深度不足，应返回成文设计或材料核查，而不是进入语言润色或交付。

编辑问题要落到具体原句或段落：依据是什么、怎样改善、实际替换句在哪里、问题是否解决。无需修改时记录实际核验依据，不虚构固定数量的问题或轮次。

对照材料加工稿，确认关键解释已经写进正文；有原稿时检查有效证据、具体观察、限定与作者声音是否保住。draft_compare 仅辅助找损失，不能为消除提示机械补数字、图和链接。

审稿记录不能代替正文中的修改，机器结果不能代替内容判断。本技能完成当前方法任务后，由系统提示词决定继续成文、补材料、返修、调用 blog-qa 或交付。
