# 作者声音：已知要求与样文观察

本文件是写作参考，不是作者身份、经历或偏好的补全。单篇文章明确要求优先；改稿以目标原文的声音为准。

## 用户明确要求

来自本仓库 AGENTS.md 与 reader-first-writing.md：标题接住读者问题，正文兑现承诺；对象、用途和范围先于细节。技术文章用具体任务贯穿主线，说明职责、因果、条件和代价。少套话、少宣传腔，保留判断与个人声音，不虚构亲历、实测、对话和引语。文学和历史按题材选择节奏。

## 仓库样文观察（尚未单独确认为固定偏好）

样本：`content/blog/20240331-network-evolution.md`、`content/blog/20261006-2147-Agent源码看不懂-先跟着一条消息走一遍.md`、`content/blog/20261007-2215-Rust无栈协程如何暂停和恢复.md`。

- 常从一个具体问题开场，接着提出下一个自然问题，让读者沿例子理解。
- 经常用“我们”带读者推演，用“你”描述任务场景；它们不证明作者亲自执行过示例。
- 概念解释跟随任务；代码、表格和图提供具体依据，示意与真实实现分别说明。
- 较新技术样文会明确版本与省略范围。旧文中的格式瑕疵、过时事实和链接写法不作为风格模仿对象。

这些样文可能经过助手编辑，只用于观察当前博客呈现，不推断完全由作者独立写作。技术样本也不用于决定文学、历史的声音。

## 使用方式

创作时按题材参考以上观察；仿写时再读取本次指定样文，不复制原句与段落。终稿检查自然程度，不能为了符合画像把每段都改成问句或强制加入“我们”。只有新反馈或可靠样文形成持续证据时才更新画像，并记录来源。
