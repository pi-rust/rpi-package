# 材料加工与成文

创作、完整改稿都先形成简短加工稿。它的作用是让写作有可用的内容和解释，不是把流程表填完。保存在 `.rpi/writing/<article-slug>/work.md`，不进入博客正文。

## 输入不同，先做的事不同

| 输入 | 要得到的工作结果 |
|---|---|
| 一句话 | 选出值得回答且能回答的主问题，找到支撑答案所需的材料 |
| 零散链接、代码、数据、笔记 | 找出材料之间的关系、反常现象或争议，形成有依据的判断 |
| 完整原稿 | 识别原稿最有价值的部分和具体缺点，决定怎样改善而不损失价值 |

不把宽泛话题直接变成百科目录。比如“写写 Go 和 Rust 性能”，先确定是在讲哪类工作、哪种条件和哪个读者问题；没有实验不能先承诺“实测谁更快”。读者和范围能推定就主动推进，确实会改变任务目的或真实性时才问用户。

- 暂定判断、待核实问题：
- 标题方向：

表格只记录决定文章判断与理解路径的核心材料，不逐项转录资料；同一依据合并记录，详细数据保留来源入口。底稿不应扩成一篇与正文等长的资料报告。短任务可以几句话写清。仅填“解释原理、说明价值、结合实际”不算完成加工。

## 加工必须做出的选择

**先核实，再确定主张。** 来源说了什么，与本文要说什么是两件事。核对来源、版本、环境、统计口径，区分事实、来源观点、亲历和推断。不同来源相冲突时先解释差异；反证改变判断就修改判断和范围。不能先定答案再挑支持材料。

读取结果被截断、只包含目录或请求失败时，不算读过所引章节。URL 中的章节锚点不保证 webfetch 只返回该节；检查实际返回内容，必要时提高读取范围、换文本版或读取另一份可靠原始说明。仍无法读到的依据标为未核实，不能给凭记忆写出的事实挂一个未读来源。

关键外部论断在底稿保留一个短的连续原文片段及来源位置，用 source_capture 留档后由 source_quote_check 核对片段是否实际存在。无工具或明确不落盘时直接对照已读原文，不伪称做了机器匹配。片段存在只是最低条件，仍要判断它是否支持正文的具体主张；404、截断之外的章节和凭记忆拼出的规范版本都不能用作依据。

**给材料一个具体用途。** 它是证明现象、解释机制、比较选择，还是限定结论？如果不能改变读者理解，不放正文；如果删掉会改变结论成立条件，保留在相关位置。关键数据、独有细节、失败与反例不能只剩一句总结。

**补上资料没有直接给出的解释。** 为什么这个现象支持此判断？还有没有别的解释？换一个条件会如何？这些解释提供文章价值，不能只在事实后接一句“因此值得重视”。

用数字解释时先写清它的统计对象与计算顺序，再复算关键关系。平均响应时间包含等待和处理，不能直接改称等待时间；“各组中位数之比”和“逐对比值的中位数”不是同一指标。调参前后表现改变可支持配置敏感性，但没有有效基线或控制宿主波动时，不能补写“牺牲了多少吞吐”这类因果结论。

加工示例，使用已有基准样稿中的量级关系：

- 材料：固定计算约 250 请求/秒；连接增加到 64，平均延迟约 256 ms，吞吐仍相近。
- 未加工的结论：“高并发不一定快，需要结合实际。”
- 可用于正文的解释：单核每秒只能处理约 250 次这类工作。闭环负载中，64 条连接各保持一个请求，轮转量级约为 64 / 250 = 0.256 秒。增加连接主要让请求多等一轮，没有提高计算能力。
- 限定：这是当前固定计算与闭环负载的近似解释，不等于所有服务都具有这个容量，也不是精确的排队模型。

这个例子展示解释应具体到哪一层，不要求所有文章带计算或采用同样段落。

## 从加工稿形成文章

先决定读者怎样一步步获得理解，再安排章节。每节有一个具体判断，材料支撑它，正文解释材料为什么有意义。只有术语、主题名和“介绍某某”的提纲不足以起稿。

图表计划是成文设计的一部分：数值证据、关系解释、截图证据和封面插画分别选形式与来源。先有明确的信息任务再制作，不能先画一批图再硬塞进文章；有了初稿后同步核对图与正文。仅需标题或大纲的任务交付该层结果，不自动继续写全文。

开头可以是任务、反常数据、场景、错误或判断；依据材料选择，不凭空编“人们普遍认为”。先让读者进入本篇对象和范围，不先铺完整历史。

例如材料已经给出“连接数翻倍，吞吐没变，等待增加”，就直接从这个差别进入；不用先写“很多开发者都有这样的困惑”来制造读者经历。能用具体结果开场时，优先让结果本身产生问题。

写正文时不复制工作表的栏目名，不机械重复“事实—解释—结论”。用合适的叙述、代码、图、例子与对照推进。新信息使主张变化时回到加工稿调整标题和结构，不能在末尾塞免责声明维持旧标题。

研究与技术文章靠有依据的解释与判断；历史同时处理时代处境与史料；文学用人物、行动、细节和节奏形成主题，不强迫段段下结论。模式给题材专属写法。

完成后，以成稿反查加工稿：答案是否兑现、证据是否到位、解释是否真的写出来、无关材料是否混入。再按 editorial-gate 做具体审稿与返修。不能把稿子只写顺了就当内容完成。

从加工稿里选择最影响判断的解释，在定稿找到它对应的具体句子；从审稿表里选择每项修改，在定稿找到实际替换。任一项只能在工作表中找到而正文没有落实，就继续返修。
