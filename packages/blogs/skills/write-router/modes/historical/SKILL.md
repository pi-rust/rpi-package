# Historical Biography Mode

## 风格参考

需要文学化历史人物叙事时，读取 `../../references/historical-style-fanghao.md`，将其作为“房昊曰天风格参考”。只提取叙事机制、节奏、人物关系和情绪组织，不复制原文句子、段落或具体情节。若用户要求纯史料分析，则不加载这份参考。

## 适用

用于历史人物、人物传记、生平、历史评价、功过、关键选择和时代处境分析。

## 文章目标

让读者理解人物在当时的处境、信息和约束下如何做选择，以及这些选择为何产生不同后果，而不是把人物写成简历或成功学模板。

## 推荐结构

```text
一个具体场景或矛盾
→ 时代与个人处境
→ 关键关系和利益约束
→ 几次关键选择
→ 选择带来的后果
→ 后人为何评价不同
→ 能力、局限与未完成之处
→ 今天如何理解，而不是简单模仿
```

## 写法

- 从一个有冲突的场景或决定切入。
- 先写人物当时知道什么、不知道什么，面对哪些约束。
- 把制度、关系、资源、风险和个人性格放在同一张图里。
- 对人物既不神化，也不因结果站在事后轻易评判。
- 允许写矛盾、失败、局限和未完成的部分。
- 可以使用叙事，但不能用文学细节伪造史实。

## 史实边界

明确区分：

- 有可靠来源支持的史实
- 不同史料或学界的解释
- 作者根据材料做出的推断
- 文学化的场景重建

不杜撰名言、心理活动、私人对话或没有来源的细节。人物评价尽量说明评价来自哪一组事实和价值标准。

## 模式自检

- 是否还原了人物当时的约束？
- 是否避免把复杂人生压缩成单线成功故事？
- 是否区分史实和推测？
- 读者是否能理解不同评价为何出现？
