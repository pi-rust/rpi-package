# Long-form Writing Mode

## 适用

用于深度文章、观点文、行业观察、复杂议题、专栏和需要完整论证的长文。

## 文章目标

帮助读者理解一个问题并形成更稳固的判断，而不是用篇幅制造深度感。

## 推荐结构

```text
具体场景或问题切口
→ 核心判断
→ 必要背景
→ 证据、案例和细节
→ 反例、张力或不同解释
→ 作者判断
→ 对读者现实选择的影响
→ 具体、克制的结尾
```

## 写法

- 从一个人、一次选择、一处矛盾或一个具体场景切入。
- 先给读者地图，再展开背景和证据。
- 让每个抽象判断都落到事实、案例、利益、选择或代价。
- 主动处理反例和读者可能的反对意见。
- 可以有明确立场，但要说明判断依据。
- 不用宏大背景、空泛升华和连续金句撑篇幅。
- 结尾回到读者的现实处境，不做无依据的未来预测。

## 证据边界

区分事实、数据、来源观点、作者推断和价值判断。没有来源的权威判断要删掉或改成有限度的个人判断。

## 模式自检

- 文章是否真的回答了一个问题？
- 证据是否足以支撑判断？
- 反对者能否看到自己被认真回应？
- 长度是否来自必要的解释，而不是重复？
