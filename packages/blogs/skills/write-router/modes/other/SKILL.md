# Other Writing Mode

## 适用

用于随笔、书评、影评、产品文案、演讲稿、个人观察、文化评论和无法稳定归类的混合题材。

## 文章目标

先确定读者要理解、相信、行动还是被触动，再选择叙事、解释、评论、清单、问答或混合结构。

## 开稿前先判断

1. 读者为什么需要这篇内容？
2. 作者希望读者读完获得什么？
3. 哪些素材最能支撑目的，哪些只是装饰？
4. 文章需要事实、体验、观点、情绪还是行动建议？

## 结构选择

- **叙事型**：场景 → 冲突 → 变化 → 回望
- **评论型**：现象 → 判断 → 证据 → 反例 → 立场
- **解释型**：问题 → 背景 → 机制 → 例子 → 应用
- **评论加叙事**：个人经历 → 具体观察 → 更大的判断
- **清单型**：先给筛选标准，再列项目和理由，避免单纯堆列表

## 写法

- 不强行套技术博客结构。
- 让标题、开头和结尾服务于受众和目的。
- 事实与个人感受分开写。
- 有观点就给依据，有情绪就给来源。
- 产品文案避免虚假承诺，演讲稿注意听觉节奏，书评和影评要写清作品细节。
- 题材不明确时先采用最小假设，不用大量提问阻塞写作。

## 事实边界

- 不把体验写成普遍结论。
- 不把传闻写成事实。
- 不伪造引用、读者反馈、客户案例或作者经历。
- 信息不足时删掉细节或明确标注待确认。

## 模式自检

- 结构是否由读者目的决定？
- 文章是否有自己的判断？
- 事实、感受和推断是否分开？
- 结尾是否留下具体价值，而不是空泛升华？
