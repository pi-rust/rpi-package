name: resource-authoring
description: Author canonical native resource-only Packages, Skills and explicitly built extensions; understand persistent instructions, validation and immutable test/publication identities.
---
Read references/layout.md for the native layout. Edit real project-owned draft source files using native tools. A Package's persistent instruction entry must be selected explicitly (normally prompts/system.md); a prompt template alone is not persistent instruction. Skills use SKILL.md frontmatter. Keep examples and references useful. Do not edit node authoring records or immutable snapshots. Validation never runs build scripts. A test creates an immutable source snapshot, installs it with the native manager and opens an exact ordinary session; a completed model round and readback are separate evidence. Editing the draft invalidates validation/current-test eligibility, not old snapshot bytes. Local publication does not update running sessions or upload publicly.
